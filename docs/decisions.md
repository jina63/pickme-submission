# 제출본 결정 기록

- 기존 개발 저장소는 Private으로 유지하고, 제출본은 이전 Git 기록 없이 별도 공개합니다.
- 연락처 표시명은 친구 1~4, 공개 이메일은 발송 불가능한 예시입니다. 실제 수신자는 서버 비공개 환경 설정에서 지정합니다.
- 문자 초대는 후속 개발 목표이며 현재 이메일 시연과 QR 재현을 지원합니다.
- 내비 위 도착 팝업을 제거하고 픽미 화면 안에서 준비 상태를 표시합니다.

## 2026-11-13 — 배포 서버 연결과 주문 예약 검증

- 차량의 초대·위치 공유 주소를 `https://pickme-relay.onrender.com`으로 통일했습니다. 비밀 설정은 서버에 보관하며 앱·제출 컴퓨터에는 포함하지 않습니다.
- 매장 경유지 목록에서 매장과 기존 동승자 순서가 확인된 경우에만 주문을 예약합니다. 시간 초과·추가 이벤트·경유지 개수만으로 성공 처리하지 않습니다. SDK가 유효한 다른 좌표를 반환하면 같은 이름이어도 통과시키지 않습니다.
- 제출용 주문 예약은 1분=60초의 실제 시간을 사용합니다. 이름만 반환하는 에뮬레이터의 목록 확인은 유지하되 미확인은 실패로 처리합니다.
- QR은 심사위원의 동승자 웹 확인, 이메일은 실제 수신자 초대 전달 시연에 사용합니다. 문자·음성·방문 순서 최적화는 이번 변경 범위에 포함하지 않습니다.
