# 매장 웹

시연 매장에서 음료 주문과 차량 도착 정보를 확인하는 대시보드입니다. **배포된 사이트는 존재하지만 현재 저장소의 이 폴더에는 안내 문서만 포함되어 있습니다.**

## 접속과 사용

1. [딱픽업 매장 주문 관리](https://pickme-ca1cd-store.web.app/)에 접속합니다.
2. **현재 매장**에서 픽업 A·B·C 중 확인할 매장을 선택합니다.
3. 새 주문·진행 중·픽업 대기 건수와 주문 목록을 확인합니다.

화면에는 실시간 연결 표시, 매장 위치, 마지막 확인 시각, 현재 매장 주문 전체 삭제 버튼이 있습니다. 주문이 없는 경우에는 빈 목록 안내가 표시됩니다. 정상 시나리오에서는 차량 앱의 주문과 매장 처리 상태를 연결해 확인합니다. 주문 삭제와 통신 장애에 대한 안내·복구 절차는 향후 보완할 예정입니다.

## 데이터 연동 확인

차량 앱의 주문 구조·상태값·권한은 [Firebase 안내](../../firebase/README.md), 주문 생성·예약 방식은 [딱픽업 안내](../../car-app/app/src/main/java/com/pickme/car/pickup/README.md)에서 관리합니다.

연동 검증은 다음 기준으로 구분합니다.

| 확인 항목 | 기준 |
| --- | --- |
| 연결 DB | 배포 웹과 차량 앱이 같은 Realtime Database를 사용하는지 확인 |
| 매장 식별자 | 웹에서 선택한 매장과 차량 주문의 `storeId`가 일치하는지 확인 |
| 주문 표시 | 별도 시험 주문을 차량 앱에서 전송한 후 해당 매장 목록에 표시되는지 확인 |
| 상태 반영 | 실제 주문 화면의 상태 변경 기능과 차량 앱의 상태 구독이 연결되는지 확인 |

팀 내 시연 영상 검증 결과를 기준으로 주문·매장 상태의 차량 반영을 포함한 정상 시나리오의 연동 검증을 완료했습니다. 확인 결과와 향후 보완 방향은 [APK 안내](../../apk/README.md#파일-확인과-검증-범위)에서 관리합니다. 상태 변경 버튼의 정확한 명칭·배치와 실제 DB 설정은 별도 배포 소스를 기준으로 관리합니다.

## 코드와 배포 범위

현재 `web/store/`에는 실행 코드·Firebase 설정 파일·Hosting 설정이 없어 저장소만으로 로컬 실행·재배포를 재현할 수 없습니다. 배포 소스 위치와 의존성·연결 설정·배포 절차가 확인되어야 합니다.

`firebase.friend.json`은 동승자 웹 배포용입니다. 매장 사이트의 별도 배포 설정으로 간주하지 않습니다.
