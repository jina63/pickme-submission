# 픽미 동승자 웹

초대 링크에서 탑승 장소를 확정하고 차량 위치·도착 정보·준비 상태를 확인하는 웹입니다. 별도 앱 설치·회원가입 없이 동작합니다.

## 접속과 실행

- Firebase 연결 환경의 배포 주소: [pickme-ca1cd-friend.web.app](https://pickme-ca1cd-friend.web.app). 주소만 열지 않고 초대 키를 포함한 **전체 링크**를 사용합니다.
- 제출 앱은 배포 서버에서 생성한 공개 HTTPS 링크·QR로 휴대폰 참여를 지원합니다. 제출 컴퓨터에는 `.env`나 로컬 서버 실행이 필요하지 않습니다. [제출 환경 안내](../../server/pickme/README.md#제출-환경과-시연-영상)를 참고합니다.
- 공개 HTTPS 초대는 차량의 QR로도 열 수 있습니다. QR은 동일 링크를 전달하며 로컬 HTTP 링크를 공개 링크로 바꾸지 않습니다. 조건은 [픽미 QR 안내](../../car-app/app/src/main/java/com/pickme/car/pickme/README.md#qr과-진행-중인-픽업-복원)를 참고합니다.
- 로컬 실행은 [중계 서버](../../server/pickme/README.md)를 사용합니다. 파일을 직접 여는 방식은 서버 API 연결을 대체하지 않습니다.
- `hosting-config.js`는 지정된 Hosting 도메인에서만 공개 DB 주소를 선택하며 다른 호스트에서는 로컬 API 모드로 동작합니다. 서버 인증 정보는 포함하지 않습니다.

## 장소 선택과 추천

현재 위치 버튼·장소 검색·지도 핀으로 위치를 선택하고 탑승 장소를 확정합니다. GPS는 버튼을 누르고 권한을 허용한 경우 한 번 요청하며 HTTPS 또는 localhost가 필요합니다. 거절·오류 시 가상 위치로 대체하지 않고 검색·수동 선택을 제공합니다.

컴퓨터 브라우저에서 연 경우 **휴대폰 GPS가 아닌 컴퓨터 브라우저가 제공하는 위치**를 사용합니다. 기기·네트워크·브라우저 권한에 따라 정확도가 낮거나 조회되지 않을 수 있으며, 이 경우 장소 검색 또는 지도 핀으로 탑승 장소를 선택합니다.

주변 추천은 선택 위치에서 **직선거리 500m 이내**의 등록 후보·외부 주차장을 통합해 가까운 순서로 최대 3곳 제공합니다. 서버의 카카오 키가 있으면 카카오 로컬을, 없으면 Overpass를 사용합니다. 외부 조회 실패 시 등록 후보가 있으면 제공하고 없으면 조회 불가로 안내합니다. 후보 없음과 조회 실패는 구분합니다.

후보는 실제 도보 경로·차량 진입·유턴·승하차 가능성을 보장하지 않으며 시설 대표 좌표가 출입구를 뜻하지 않습니다. 후보 관리는 서버의 `pickup-candidates.json`, 허용 필드는 [Firebase 규칙](../../firebase/README.md)을 함께 확인합니다.

## 차량 정보 표시

- 최신 공유 데이터를 약 3초마다 확인하고 차량 위치·Pleos 픽업 ETA·카페 경유 상태를 표시합니다. 차량의 공유 조건·기간은 [픽미](../../car-app/app/src/main/java/com/pickme/car/pickme/README.md#차량-정보-공유)에서 관리합니다.
- 유효한 ETA가 3분·1분 이내이면 도착 안내를 표시합니다. 준비 완료는 직접 입력이며 실제 탑승 자동 판정이 아닙니다.
- 차량 정보가 20초를 초과해 갱신되지 않으면 ETA·카페·경로선을 숨기고 마지막 차량 위치를 흐리게 표시합니다. 공유 중지 시 차량 정보를 숨깁니다.
- 예상 경로선은 카카오모빌리티 계산 결과이며 실제 Pleos 안내 경로와 다를 수 있습니다. 카카오 키·정상 응답이 필요하고 차량 300m 이동 또는 1분 경과 후 다음 공유 갱신 과정에서 재계산을 요청합니다.
- 카페 핀과 옆모습 차량 아이콘을 사용하며 매장 대기 시간은 ETA에 포함되지 않습니다.

## 파일 지도와 외부 연결

| 파일·연결 | 역할 |
| --- | --- |
| `index.html`·`friend.js`·`styles.css` | 동승자 화면·상태 처리·스타일 |
| `place-search.js` | 장소 검색 |
| `hosting-config.js` | Hosting 도메인별 DB 연결 선택 |
| `driver.html`·`driver.js` | 로컬 운전자 시험 화면. Hosting 배포 제외 |
| `vendor/leaflet/` | Leaflet 1.9.4와 라이선스 |
| OpenStreetMap·Photon | 지도 타일·장소 검색. 네트워크 연결 필요 |

주변 주차장 검색에는 서버에서 약 100m 단위로 반올림한 좌표를 사용합니다. 예상 도로 경로 계산에는 차량·카페·탑승 좌표를 카카오모빌리티에 전달합니다. 지도 타일·검색·길찾기의 데이터 전달 범위를 동일한 것으로 설명하지 않습니다.

## Hosting 배포

저장소 루트에서 실행합니다. `firebase.friend.json`은 친구 전용 사이트와 이 폴더를 지정하며 운전자 시험 화면은 제외합니다.

```bash
firebase deploy --only hosting --project pickme-ca1cd --config firebase.friend.json
```

데이터 필드가 바뀌면 [규칙 검증·배포](../../firebase/README.md#규칙-검증과-적용)와 호환되는 버전을 함께 적용합니다. Hosting 배포만으로 중계 서버·차량 APK가 갱신되지는 않습니다.

## 한계와 보완점

장소 추천은 거리 중심이며 정차 적법성 판정이 아닙니다. 예상 경로는 실제 내비 경로와 다를 수 있고 외부 서비스 장애·통신 지연 시 정보가 제한됩니다. 도로·도보 접근성 반영과 장애 후 표시·복구 검증이 보완 범위입니다.
