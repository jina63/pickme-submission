# 픽미 친구 웹

초대 링크를 받은 친구가 위치를 허용하고 탑승 후보를 확인하거나 지도 핀을 옮겨 탑승 장소를 확정하는 웹입니다.

배포: https://pickme-ca1cd-friend.web.app (전체 초대 링크의 fragment가 필요합니다)

실행·Firebase 배포·제약은 `server/pickme/README.md`를 확인하세요. `hosting-config.js`에는 공개 데이터베이스 주소만 있고, Firebase API 키나 관리자 인증 정보는 없습니다. `firebase-config.js`는 사용하지 않습니다.

Leaflet 1.9.4는 `vendor/leaflet`에 라이선스와 함께 포함합니다. 지도 타일 출처는 OpenStreetMap이며 네트워크 연결이 필요합니다. GPS는 버튼을 눌러 권한을 허용한 경우만 한 번 요청합니다.

실제 GPS 확인: **내 위치 사용**과 지도 위 **내 위치** 버튼으로 기기의 현재 위치를 한 번 요청합니다. 권한 거절·시간 초과 시 한양대 위치로 대체하지 않고 오류를 표시합니다. 장소 검색이나 지도에서 선택하는 방법도 지원합니다.

주변 추천: '내 위치 사용'·지도 위 '내 위치'·장소 검색 뒤에 지도 아래 '주변에서 타기 좋은 곳' 목록이 나옵니다. 첫 줄은 내 위치(또는 검색한 곳)이고, 그 아래에 500m 안의 팀 등록 후보와 카카오맵 주차장을 가까운 순서로 최대 3곳 보여 줍니다. 검색 실패와 후보 없음을 구분합니다. 차량 진입 방향·유턴·정차 가능 여부까지 판단하는 추천은 미구현이며, 시연 후보도 검증된 승하차 장소라는 뜻은 아닙니다.

운전자가 수락하고 공유를 시작하면 차량 위치와 친구 탑승 장소까지의 예상 시간을 표시합니다. 딱픽업 카페가 실제 내비 경로에서 친구보다 앞에 확인되면 카페 이름·경유 상태와 가게 모양 카페 핀(창문 속 라떼 컵, 핀 끝이 카페 위치)을 표시합니다. 자동차는 지도에서 옆모습 아이콘으로 보입니다. 서버가 카카오모빌리티 길찾기로 계산한 예상 도로 경로(차량 → 카페 → 탑승 장소)를 파란 선으로 그리며, 실제 내비 경로와 다를 수 있다고 안내합니다. 상표·로고는 쓰지 않습니다. 매장 대기 시간은 예상 시간에 포함되지 않으며, 연결 지연·중지 시 카페 정보는 숨깁니다.

## 초대 링크를 여는 방법

최종 목표는 문자 메시지로 초대 링크를 전달하는 것입니다(문자 발송 미구현). 현재 시연 영상은 이메일 링크로 진행하며, 심사위원이 팀원의 메일함 없이 같은 친구 웹을 확인할 수 있도록 차량 화면에 같은 링크를 여는 QR을 추가했습니다. QR은 문자 링크를 열었을 때의 화면과 흐름을 재현하는 보조 수단이며, 이메일과 같은 초대 링크를 사용합니다. 초대 화면의 **휴대폰으로 초대 열기 · QR** 버튼을 사용합니다. 공개 HTTPS 링크가 필요하며, 휴대폰 실물 스캔 확인은 아직입니다.
