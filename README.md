# Pickme — 픽미 & 딱픽업

이 저장소는 개인정보와 비밀 설정을 분리한 공모전 제출용 소스 사본입니다. 기존 개발 이력은 별도 개발 저장소에 보관하며, 제출 저장소의 최초 커밋 시점을 전체 개발 시작일로 간주하지 않습니다.

Pickme는 Pleos 차량 환경에서 동승자 픽업과 이동 중 음료 픽업을 지원하는 Android 애플리케이션입니다. **픽미**는 초대·탑승 장소·차량 도착 정보를 연결하고, **딱픽업**은 경로와 준비 시간을 기준으로 매장과 주문 전송 시점을 조율합니다.

## 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 픽미 | 링크·이메일·QR 초대, 탑승 장소 확정, 경유지 연결, 차량 정보·준비 상태 공유 |
| 딱픽업 | 음료 선택, 매장 추천, 경유지 요청, 주문 예약·전송·상태 표시 |
| 구성 | 차량 앱, 동승자 웹, 중계 서버, Firebase Realtime Database |
| 구현 범위 | Pleos 에뮬레이터·로컬 중계 서버 중심의 시연용 프로토타입. 제출용 release에서 최신 픽미·딱픽업 화면 사용 |

## 사용 흐름

1. 차량 내비에 목적지를 설정하고 홈에서 픽미 또는 딱픽업을 선택합니다.
2. 픽미에서는 초대를 받은 동승자가 웹에서 탑승 장소를 확정하고 운전자가 픽업을 수락합니다.
3. 딱픽업에서는 음료·추천 매장을 확인하고 경유지 요청과 주문 예약을 진행합니다.
4. 차량 앱과 동승자 웹은 내비·서버를 통해 진행 정보를 공유하며, Firebase 설정 여부에 따라 로컬 모드와 클라우드 모드로 구분됩니다.

실행은 [차량 앱 안내](car-app/README.md)에서 시작합니다. **제출본에는 `.env`가 포함되지 않아 픽미 이메일 전송을 사용할 수 없습니다.** 차량의 초대 링크를 복사해 에뮬레이터를 실행한 컴퓨터 브라우저에서 열며, 동승자 응답은 서버 메모리에 저장됩니다. 휴대폰·이메일·Firebase를 사용하는 영상 촬영 환경과의 차이는 [제출 환경 안내](server/pickme/README.md#제출-환경과-시연-영상)를 참고합니다.

## 한계와 보완점

현재는 실제 결제·상용 매장 주문 시스템이 연결되지 않은 프로토타입입니다. 시연용 매장 대시보드는 별도 배포되어 있으며 [매장 웹 안내](web/store/README.md)에서 접속·연동 확인 범위를 설명합니다. 픽미는 release에서도 로컬 중계 서버가 필요합니다. 최종 서명 release APK, 배포 서버 주소의 차량 앱 적용, 다른 기기의 전체 흐름 검증은 완료 여부를 별도로 확인해야 합니다. 서버의 상태 파일 저장은 구현되어 있으나 실제 배포·재시작 복원 검증은 별도입니다.

기능별 예외와 개선 방향은 각 상세 문서의 **한계와 보완점**을 기준으로 확인합니다. 코드 구현, 제어된 시연, 실제 주행 검증은 구분하며 기존 시험 기록을 현재 코드 전체의 검증 완료로 간주하지 않습니다.

문서와 코드·시험 정리에 생성형 AI 도구를 보조적으로 사용했습니다. 구현·제어된 시연·실제 주행 검증 범위는 구분하여 기술합니다.
