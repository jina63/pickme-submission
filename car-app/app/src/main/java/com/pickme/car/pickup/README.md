# 딱픽업 — 가는 길 주문

이동 경로와 음료 준비 시간을 비교해 매장을 추천하고 도착 시점에 맞춰 주문을 전송하는 기능입니다.

## 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 흐름 | 음료 선택 → 매장 추천 → 경유지 결과 처리 → 주문 예약·전송 → 상태 표시 |
| 핵심 계산 | 우회·대기를 합산한 추천 점수와 이동·준비 시간 차이를 이용한 예약 |
| 메뉴 | 돌체라떼·아메리카노·카페라떼 중 1종, 수량 1잔 |

## 현재 구현된 범위

- 매장 정보 조회와 추천·예상 대기 표시
- 내비 경로 변경 감지에 따른 추천 재계산 (확인 버튼 선택 전)
- 매장 경유지 요청 결과 처리 후 예약·주문 전송
- 같은 화면의 연속 확인 입력 제한과 Firebase 주문 상태 구독
- 예약 후 화면을 닫아도 앱 프로세스가 유지되면 전송 지속

## 사용 흐름

1. 내비 목적지를 설정하고 홈에서 **딱픽업**을 선택합니다.
2. 메뉴를 선택하고 **매장 추천받기**를 누릅니다.
3. 매장·이동·우회·준비 시간과 예상 대기를 확인합니다.
4. **이 매장에서 받을게요**를 누르면 경유지 추가를 요청하고 내비 연동이 성공으로 처리된 뒤 예약합니다.
5. 정해진 시점에 주문을 전송하고 주문 상태를 표시합니다.

내비 요청 실패·주문 저장 실패는 추천 화면에서 안내합니다. 이미 전송된 주문의 상태 조회 실패는 진행 화면에서 안내하며 자동 재주문하지 않습니다. 목록에서 경유지·순서를 확인하지 못하면 예약하지 않으며, [경유지 반영 기준](../core/navi/README.md#매장-경유지)을 함께 확인합니다.

## 매장은 어떻게 고르는가

```text
예상 대기 = max(0, 준비 시간 − 매장까지 이동 시간)
추천 점수 = 1.5 × 우회 시간 + max(0, 예상 대기 − 2분)
우회 시간 = max(0, 차량 → 매장 → 목적지 시간 − 목적지 직행 시간)
```

- 유효한 좌표 정보가 없는 후보는 제외합니다.
- 우회 상한은 `max(10분, 목적지 직행 시간의 35%)`입니다. 상한 이내 후보 중 최저 점수를 선택하며 모두 상한을 넘으면 최저 점수 매장과 우회 경고를 표시합니다.
- 점수가 같으면 실제 예상 대기·매장까지 이동 시간이 짧은 순서로 선택합니다. 화면의 대기는 점수 계산용 2분을 차감하지 않습니다.
- 차량 → 목적지·매장 시간은 Pleos 조회값을 사용합니다. 매장 → 목적지와 조회되지 않은 매장 구간은 직선거리·도로 보정 비율·평균 속도로 근사합니다.
- 내비 조회 전체 실패 시 고정 시간을 사용하고, Firebase 매장 읽기 실패 시 코드의 기본 후보를 사용합니다.

예를 들어 직행 32분일 때 우회 상한은 11.2분입니다. 우회 0분·대기 28분인 후보의 점수는 26, 우회 11분·대기 0분인 후보는 16.5이므로 후자를 선택합니다.

## 주문은 언제 전송하는가

```text
전송 대기 = max(0, 매장까지 이동 시간 − 준비 시간)
도착 후 예상 대기 = max(0, 준비 시간 − 매장까지 이동 시간)
```

- 이동 13분·준비 9분이면 계획상 4분 후 전송합니다. 이동 9분·준비 13분이면 즉시 전송하고 도착 후 약 4분 대기를 표시합니다.
- 시간 계산은 내비 연동 성공 처리 시점부터 시작하며 추천 시 이동 시간을 사용합니다.
- 제출용 전송 대기는 실제 시간을 사용합니다. 계획상 1분은 60초이며, 4분 대기는 실제 240초입니다 (`OrderScheduler.SECONDS_PER_PLAN_MINUTE = 60`).
- 저장하는 `etaAt`도 성공 처리 시각에 실제 분 단위 이동 시간을 더한 값으로, 예약 대기와 같은 시간 기준을 사용합니다.

## 실행하고 시험하기

차량 앱 실행 후 목적지와 Firebase 매장을 준비하고 메뉴 → 추천 → 확인 → 주문 흐름을 실행합니다. `prepMin`을 이동 시간보다 크게 설정해 대기 계산을 확인하고 시험 후 복원합니다. 주문 상태 변경 시험은 Firebase 문서의 상태값을 기준으로 진행합니다.

기본 후보의 지역별 시험 목적지는 수원시청·판교역·킨텍스입니다. 추천 결과는 차량 위치·교통·Firebase 준비 시간에 따라 달라지므로 특정 매장 선택을 보장하지 않습니다.
